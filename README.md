# Northline Digital Studio website

A responsive static website for a small digital-template storefront. It includes three sample downloads, custom-work enquiry prompts, and responsive mobile navigation.

## Preview locally
Open `index.html` in Chrome. Keep `styles.css`, `script.js`, and the `downloads` folder alongside it.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new **public** repository, for example `northline-digital-studio`.
3. Upload the contents of this folder (the `index.html`, `styles.css`, `script.js`, `README.md`, and `downloads` folder). Upload the files/folder contents, not the outer ZIP.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**; select `main` and `/ (root)`, then save.
6. Wait for GitHub Pages to publish. The public website address will appear in the Pages settings, usually `https://YOUR-USERNAME.github.io/northline-digital-studio/`.

GitHub Pages hosting is free for public repositories. The repository and downloadable files will be public, so do not upload private customer information.

## Before publishing
- Replace the brand/contact wording if you choose a different business name. `Northline Digital Studio` is a working name; check business-name and domain availability before investing in branding.
- Add your real Fiverr/Upwork profile links and a business contact email once you have them. No email address or external profile URL has been invented in this draft.
- The enquiry form currently copies a message to the visitor's clipboard. It does not send, store, or collect form submissions. Connect a form provider or add your verified email/contact links if you want direct submissions.
- The downloadable workbooks and PDF are demo samples. Check formulas, tax settings, wording and suitability before using them for real customer transactions. The workbook's example HST rate is not a substitute for checking current tax obligations.
- Paid products are represented as custom-order enquiries for now. Add a secure checkout/digital delivery service when you are ready to sell fixed-price downloads.
